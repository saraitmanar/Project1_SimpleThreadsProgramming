Deijen - report
Implemented Exit:
When Exit(status) is called, the system now prints the required line: Process [pid] exits with [status]. Marks the PCB as exited and stores the exit status. Wakes up any parent process that is waiting with Join(). Removes children by clearing their parent pointers. Frees all physical pages used by the exiting process. Releases the PID and removes the PCB from the process manager. The system terminates the thread with currentThread->Finish().
Implemented Exec: Prints the required line when Exec is invoked: Exec Program: [pid] loading [name]. Reads the filename from user memory using the pointer in Register 4. Opens the executable file; if the file does not exist, returns -1. Deletes the old AddrSpace of the current process. Creates a new AddrSpace using the loaded executable. Initializes user registers and replaces the current program with the new image. Returns 1 to indicate successful exec, then immediately jumps into user mode using machine->Run().
